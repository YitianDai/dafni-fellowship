# Climate-Driven Cascading Failure Risk in Electricity Transmission Networks

**DAFNI Fellowship 2026–2027 · Dr Yitian Dai, The University of Manchester**

Website: **https://yitiandai.github.io/dafni-fellowship/**

## About the Fellowship

Extreme weather is now the leading cause of large power interruptions in Great Britain, and a decarbonising system with renewable generation sited at the network periphery changes how failures spread. This Fellowship, hosted on the [Data and Analytics Facility for National Infrastructure (DAFNI)](https://www.dafni.ac.uk/who-we-are/dafni-fellowship-programme/), brings weather-driven vulnerability assessment and dynamic cascading failure simulation onto the DAFNI platform, so that resilience evidence for the GB transmission system can be reproduced, examined and reused.

The work has four strands:

- **Build the demonstrator.** Deploy a containerised cascading failure workflow on DAFNI that couples windstorm hazard fields with an open GB transmission network model and dynamic protection logic.
- **Map climate-driven vulnerability.** Translate reanalysis and climate projection data into line-level outage probabilities, and identify the corridors and cut sections where risk concentrates.
- **Connect infrastructure models.** Expose transmission outage scenarios as outputs that other DAFNI workflows can consume, to study interdependencies with distribution networks, transport and communications.
- **Translate evidence into practice.** Gather requirements from network operators and regulators through a stakeholder workshop, and turn them into reusable workflows and technical recommendations.
